# Bat Dev88

Quero criar uma plataforma web para gerar sites e aplicativos com IA. A interface deve ter estilo split-screen com chat de IA à esquerda e área de visualização à direita (com preview interativo em tempo real e aba para ver o código gerado). Conectar à API do Google Gemini onde o usuário pode inserir sua chave, gerar código moderno em React com Tailwind CSS, e incluir botões para baixar o projeto em ZIP e exportar para Vercel.

This project was built with [Lovable](https://lovable.dev).

**Live app**: https://bat-dev88.lovable.app
